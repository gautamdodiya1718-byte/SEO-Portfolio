# Gautam Dodiya — SEO Portfolio

This static website uses the supplied `SEO-Portfolio-main.zip` homepage as its design source. The original `style.css`, `script.js`, favicon, type choices, Tailwind setup, and supplied visual assets are preserved unchanged.

## Pages

- `index.html` — Home, retaining the source site's layout and visual treatment
- `work/index.html` — all selected project pages
- `work/<project>/index.html` — individual reusable project overview pages
- `systems/`, `approach/`, `about/`, `resume/`, `contact/` — supporting portfolio pages

The new project pages use structural placeholders for project facts that were not present in the ZIP. Existing homepage metrics and claims were retained from the supplied site. The example email address from the source homepage was removed; contact details are left open until confirmed.

For local preview, serve this folder from its root so the original relative asset paths and page links work.
